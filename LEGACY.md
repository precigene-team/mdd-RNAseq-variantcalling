## TL;DR

**What ships:** three modules, Input-only, in order — `01_core_alignment/` steps
`01`-`10` (FastQC → trim → rRNA filter → STAR → Qualimap → featureCounts gene-level →
counts QC → MultiQC), `02_dge_analysis/` steps `01`-`09` + `config.yaml` (DESeq2 DGE,
PCA, enrichment, heatmap), `03_variant_calling/` steps `01`-`22` (GATK joint calling →
SnpEff annotation → MDD candidate table → polygenic burden). The pipeline **stops at
variant calling and burden testing**; the last delivered artifact is the burden figures.
`run` drives it: `core`, `dge`, `vc`, `vc-post` (steps `08`-`22`), `all`.

**What was retired:** the whole MeRIP/TRESS/ASM thesis arm — peak counting, TRESS peak
calling and consensus peaks, DMR finding, allele-specific methylation, AME motif
enrichment, methylation and metagene plots, the clinical translation stage, the GWAS and
VEP matrices, and every GTEx artifact. `17` survives as a **sourced helper** (styling +
collection filters for `18`-`22`), never invoked; `16` is a table script that draws
nothing, and `15` plots only result files.

**Where the retired code lives:** scripts deleted from `01`/`02` are archived under
`_legacy/`, which is gitignored — **not part of the delivered repository**. MeRIP blocks
removed *inside* `02` scripts are not archived (the git history holds them). Docs archived
to `docs/_archive/` (11 files).
